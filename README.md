# AI for Lawyers

This repository contains a portfolio and reference copy of **Session 1 — Using AI Effectively in Legal Practice: Limitations, Prompting, and Process**, prepared by Nayan Banerjee / Plain Signal Advisory.

The document introduces:

- how AI systems work and where they can fail in legal practice;
- practical methods for setting up matters, instructing AI, and managing conversations; and
- process thinking, workflows, flowcharts, and decision trees for deciding where AI belongs.

The homework section has been intentionally omitted from the uploaded document. The repository includes the remaining session material, recommended pre-reading, and sources and notes.

This repository is published for portfolio and reference purposes only. It is not legal advice, and the document's legal and technical claims should be independently verified before reliance.
